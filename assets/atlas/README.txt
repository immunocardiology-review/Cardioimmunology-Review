STATUS AND LIMITATIONS
A curated educational synthesis, not a systematic review or clinical guideline. Independent scientific peer review is not complete. Six reading families and 153 undirected conceptual edges are navigation aids, not causal claims. Source identities were checked using Crossref and primary publisher or repository pages. Source selection is targeted and purposive; no exhaustive screening, duplicate independent selection, formal risk-of-bias assessment or GRADE rating was performed. Counts describe catalogue coverage, not completeness of the discipline. Refer to each source for the complete author list and to the method for remaining gaps. Codex assisted drafting, data preparation and technical checks. Future releases should remain in the same DOI version lineage.
